# AV Audio application brief

Audio operators need one channel identity across input planning, patch assignment and line check, plus a separate speaker zone plan. The first useful slice edits these records in one console, shows gaps, saves explicitly, exports JSON and previews imports from the four original browser tools. Original localStorage entries remain untouched. Imports retain each original JSON payload and all row fields in source snapshots, with a stable source-record fingerprint and a previewed merge into active working rows. Input, patch and line-check statuses stay separate; a line-check issue takes precedence in the channel summary. A malformed or unsupported file cannot change the working document.

Flow: start a channel, assign stagebox/input and destination, mark a line check with operator and problem, then review gaps. Speaker zones remain separate. Save stores one `sbd.avAudio.v1` document; export is the portable backup. If saved bytes are unreadable, Save is blocked and the original bytes can be downloaded before recovery. The shared console stores only panel arrangements. No sound measurement, console control, RF coordination, comms semantics, or safety verdict is implied.
