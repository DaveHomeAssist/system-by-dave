# Envision

Envision gives event designers a browser-local prompt studio and layered flyer editor at `/envision/`. Open an existing AfterJinx project to revise its billing and event copy against the original background, then export an editable project or PNG. The field guide credits the No Nonsense examples. Only published reference thumbnails ship with the application.

Saved briefs belong to this origin and browser. Portable layout files use the existing nnc-layout-1 format. Open a saved file from the original kit to continue on this site. Keep the direct route and its editor out of the sitemap. Acceptance covers prompt generation, saving and reopening a brief, importing a portable layout, and exporting a revision at the source canvas size.

Both downloads use the event name shown in the editor. Older layout files start with their imported filename. Correct the name before saving if a previous export carries another event’s name. Saved projects retain the name even when the file is renamed.

In Saved events, **Export brief** downloads the event name, resolved prompt and approved copy. Import the file into Envision Personal Studio to continue on your own GPU. The private studio keeps artwork versions, protected edits, campaign layouts and export history on the owner's hardware. Installation and recovery are covered in the [personal studio guide](../apps/envision-studio/README.md).
