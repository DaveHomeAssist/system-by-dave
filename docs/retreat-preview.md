# Retreat Series preview

Publish the six supplied retreat pages for review at [Retreat Series](https://systembydave.com/retreat/). Visitors arrive from the shared URL and move between the welcome, retreat listings, experience, series introduction, FAQs, and contact pages.

Keep the preview out of the main site navigation and sitemap, and set each page to noindex. The URL is public and requires no sign-in. Dates, organizer details, and registration remain placeholders. The preview has no backend, registration form, or external dependencies. The existing Pages workflow publishes the folder with the site.

Acceptance requires the typed URL and each page and asset to resolve on the production domain, the FAQ disclosures and theme control to work, and the viewport to contain the shell at 1440 × 900 and 375 × 812. Remove the preview through the same Pages workflow once the review is finished and removal is requested.
