# Website viewport and theme completion

Dave selected WEBREVIEW-D1 on October 12, 2026: convert the System homepage,
AV landing and profile to viewport layouts with complete theme controls.
The October 13 single-console decision supersedes the AV landing portion: the
release preserves `/av/` and retired-page redirects. The public reader now applies
to the System homepage and profile. This authorizes implementation, not final approval or publication of PRs 319–321.

Preserve existing copy, branding, product destinations, profile contact fragments,
AV Stage Slate first-use and the shared saved AV preference. System pages start
light without a saved choice. Both expose a visible, persistent theme control.

Use a shared progressive enhancement: authored sections become subject tabs;
content exceeding the available height is paginated, not discarded or shrunk.
Desktop tabs sit above the content; phone tabs sit in a bottom rail. Previous and
Next controls expose every page and keyboard focus reveals its containing page.
Retain direct fragments, browser history, browser find, readable no-script content,
and a full print document. No new dependencies or operational app redesign.

Acceptance: light/dark, 1440×900, 375×812, 680 breakpoint, 844×390,
320×256 stress and 3840×1080 ultrawide. Check root dimensions, every subject and
page, keyboard focus, contact links, history, theme persistence, print expansion,
no-script fallback and console errors on Dominic. Automated browser coverage is
not physical-device or Dave's final product acceptance.
