Field reference

Count the connectors by their jobs.

The HD8 ISO has two physical SDI auxiliary outputs. Its USB webcam output is also routable. The manual’s “three auxiliary outputs” heading includes that webcam destination; HDMI is not a third physical SDI aux.

Field reference

Trace the destination before switching it.

  1. Identify the connected destination and label at the rear panel.
  2. Select the intended aux destination in the switcher controls or ATEM Software Control.
  3. Choose the source for that destination.
  4. Observe the actual receiving monitor or device. A selected source in the interface is not proof of a completed physical path.

Confirm the USB webcam routing separately when it is used. Do not infer an installed aux count or downstream patch from a heading in a reference sheet.

Field reference

Interlaced standards change the recording options.

With an interlaced switcher standard, you can record or stream, but not both at once. ISO recording is unavailable.

Check the selected switcher standard before planning a capture. A distribution record that says 1080i is not enough to establish the current switcher configuration.

  1. Read the actual video standard on the installed switcher.
  2. Decide whether the task is streaming, program recording or ISO recording.
  3. Check that the intended combination is supported in that standard.
  4. Run a short rehearsal capture and inspect the files or receiving stream.

Do not change the show’s video standard solely to enable a recording option; agree and verify the complete downstream path first.

Field reference

58 Fairlight channels is a supported model claim.

The current HD8 ISO technical specifications identify a 58-channel Fairlight mixer. Keep the number tied to this model and its vendor specification. It is not a count of microphones connected at a particular venue.

Check the selected audio source, meters and monitored destination before using the program output. Label physical audio paths separately from the software mixer’s available channels.

Field reference

Streaming sources have a compatibility boundary.

The HD8 ISO supports network streaming sources from compatible Blackmagic cameras. Network discovery and a camera streaming engine do not imply support for every IP camera or for arbitrary NDI sources.

Use the manual’s streaming-source setup and check the installed software and camera combination before planning the input.

Field reference

Hand back a verified path.

  • Record the model badge, installed firmware and video standard.
  • Match each aux label to its physical destination.
  • Confirm camera return/control and multiview connections by function.
  • Keep uncertain labels marked untraced until the receiving end is observed.
  • Recheck program picture and monitored audio after any change.

Venue-specific input labels, macros and preshow habits belong with the department’s operational record. This page describes the model.
