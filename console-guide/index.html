How this list is built

  • Specs were checked against each manufacturer's product or tech-spec page on 28 October 2026. Makers change pages; follow the link before you book a truck.
  • ETC lists Eos capacity as outputs (DMX addresses); MA lists parameters; others list universes. Each is shown in the maker's own terms.
  • Many makers call their sizes and weights typical. Folding consoles show each published position.
  • No photos are copied here. Use "Photos and specs" to see the console on the maker's site.
  • Spotted a wrong number? Email avbydave@gmail.com with the maker's link.
