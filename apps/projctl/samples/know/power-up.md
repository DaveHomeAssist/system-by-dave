# Sample power-up and power-down order

A sample for the simulator. The real order lives in the private documents folder on the relay
computer. Waits marked "researched" come from the manufacturers' documents and are not yet
tested on the rig.

## Once, before the first night this order is relied on

- On each Panasonic projector (lanes A, B and D), check that PROJECTOR SETUP > STANDBY MODE
  reads NORMAL. In ECO the projector's network is off in standby, so the morning power on from
  this page cannot reach it. Researched, not yet tested.
- Any setting change is a rig change and waits for the video lead's go.

## Morning

1. Check the show computer first: awake and unlocked, five displays, the control monitor as
   the main display. If it was locked, treat every output as suspect and tell the video lead.
2. Power page: Turn all on. The run goes C, B, A, then D about 10 s after A.
3. Nothing is sent to a lamp unit for 60 s after it lights. Then the run reads its power and
   lamp state, and watches it for 3 minutes.
4. A lamp message at the strike: photograph it. If the unit then turns itself off, the run
   waits for it to cool, then 75 s, and tries once more. A second failure is a service call.
5. Wait for "All four on", about 4 minutes.

## Night

1. Power page: Turn all off. The Night tab shows each lane: lamp units about 170 s of
   cooling, the top laser about 5 s, the Barco about 30 s to READY. All off in about 3 min.
2. Never cut mains while a lamp unit is cooling.
3. Leave only when the page says "Safe to leave the building": all four read OFF.

## Two-show days

- Leave everything on between the shows, shutters closed.
- After the first long shutter hold, check the lamp units' lamp power and brightness. A lamp
  set to normal power can drop to eco power by itself when the shutter stays closed a long
  time. Researched, not yet tested.
