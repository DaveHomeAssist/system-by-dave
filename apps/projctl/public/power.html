    How this page works

    • Morning: Turn all on. Night: Turn all off. Confirm to start one run for all four. In Blind, both buttons preview the sequence.
    • Night: the Night tab shows each lane's expected wait and what it reads now. All off takes about 3 minutes.
    • Wait for the banner. "All four on" in the morning, about 4 minutes, because the two lamp units are watched for 3 minutes after they light. "Safe to leave the building" at night, only when all four read OFF. Until it shows, the run is not finished.
    • If the banner says "Not all four on" or "Not safe to leave yet": it names the lane. Look at that surface, then call the show backup.

    Never

    • Never cut power at a breaker, a power strip or a mains switch. A lamp projector must cool with its fans running, about 3 minutes.
    • Never shut down, log out of or unplug the show computer or its control monitor.
    • Never open or save the show file.
    • Never touch lens, focus or zoom.

    If something is wrong

    • A warning light, a cover error or a lamp message: photograph the screen and the indicator lights, then call the show backup or the video lead.
    • "Lamp fault" on a lamp unit: it turned itself off after lighting. The run waits for it to cool and tries once more. If it fails again, it is a service call: photograph any message and call the video lead.
    • Lane C reads deep standby: the morning power on cannot reach it from this page. Tell the video lead before you leave.
    • The relay is not answering: this page can send nothing. Call the video lead.

    This page cannot tell

      Shared sign-in

      Everyone who uses this page signs in with the same passcode. The relay records each command and its time. It does not record who sent it.

      The on and off run is shared too: if someone else has started it, this page shows the same run and waits for it to finish.

      The same passcode also opens the main console.
