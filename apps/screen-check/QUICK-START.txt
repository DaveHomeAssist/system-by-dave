FROZEN SCREEN CHECK — MAC STUDIO

1. Unzip Frozen-Screen-Check-1.0.0.zip.
2. Move Frozen Screen Check.app to Applications and open it.
3. Click Enable at Login. If macOS requests approval, allow Frozen Screen
   Check in System Settings > General > Login Items & Extensions.

The menu bar shows a check mark when all expected output settings match.
Open its menu and choose Check Now or Open Checklist at any time. Closing
the checklist leaves the lightweight checker running. Quit ends this run;
Disable turns off future login checks.

After boot, checking starts when the production user logs in. It cannot
check the production desktop before login or unlock FileVault for you.
Login allows 12 seconds for displays to appear. Display changes and waking
the Mac trigger another check automatically. These later checks update
the menu-bar status without interrupting your work with a window.

EXPECTED SHOW OUTPUTS
Two Panasonic PT-DW830U outputs: each 1920 x 1200 at approximately 60 Hz
One Panasonic PT-RZ970 output: 1920 x 1200 at approximately 60 Hz
One Barco UDM-4K output: 1920 x 1200 at approximately 60 Hz
Field Monitor: 1920 x 1080 at approximately 60 Hz

The two identical Panasonic models are verified as a pair. This does not
identify which is A versus D. These are Mac output requirements, not the
physical pixel counts of the projector panels.

CHECK means inspect the row. It may be missing, inactive, mirrored,
scaled, at the wrong resolution/rate, or have an unrecognized identity.
The app never changes outputs, power, inputs, shutter, focus or mapping.
A match does not prove that the projector is receiving or showing light.

Profile opens the local profile folder. If the approved show setup changes,
edit show-profile.json, save, and Check Now. Invalid profiles fail visibly.
Export Report saves the current observations for support.

Requires an Apple Silicon Mac running macOS 13 or later. No Node, Python,
browser, backend, network connection or developer tools are required.
